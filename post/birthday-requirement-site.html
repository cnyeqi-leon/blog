生日会需求收集页：提需求 / 提意见都能提了

给班级生日会做了一个需求收集页，同学扫码就能提。

两个入口

  • 提需求：跟助手多轮对话，把想法说清楚，最后确认提交；每台设备只能提交 1 次
  • 提意见：一句话 + 类型（环节 / 游戏 / 物料 / 时间安排 / 其他），最多 3 条

后台

有数据看板：需求条数、意见分类、24 小时提交曲线，还有一个中文汇总可以直接发给筹备组。

  • 提交页：https://junshi-pc.tailf36923.ts.net:10000/
  • 看板：/dashboard?k=（有口令）

这个页只是内网/临时服务，关电脑就没了；正式对外的东西放 GitHub Pages。
